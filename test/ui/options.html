Presentation mode

Prevents stored values from being revealed at all. Turn this on before screen-sharing, recording or presenting, so a value cannot be exposed by a stray click.

Clear all stored values

Removes every placeholder mapping for every tab, and the counters shown in the popup. Placeholders already sent in a conversation cannot be restored afterwards.

What this does

Personal information is detected in the prompt and replaced with a placeholder before the request leaves this machine. The original values are kept locally so they can be put back into the reply. The service receives only the placeholder.

What it does not do

  • It does not detect everything. Only the listed types are matched, by pattern. Anything unrecognised is sent unchanged, and no measurement here bounds how much that is.
  • The page could observe the extension. Intercepting the request requires running in the page's own JavaScript environment. A script that loaded first could in principle watch the handover. This cannot be eliminated on this extension platform.
  • Stored values are not encrypted. They are in session storage in the clear until the tab closes.
  • Restoration depends on the model. If the model does not repeat a placeholder, the value cannot be put back. The popup reports when that happens.
